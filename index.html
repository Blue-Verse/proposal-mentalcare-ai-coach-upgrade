핵심 요구사항 분석

첨부된 우선순위 기능표(1~4순위, 총 35개 기능)를 분석하여 각 영역(AI 코치·오늘의 미션·감정일기·마음편지·오늘의 격언·회원가입·어드민·UI/UX·브랜딩)의 과업을 도출하였습니다.

  • [1순위] AI 코치 백엔드 고도화 — 메모리 v1(대화 요약 저장·주입) + 코치별 few-shot·기법 스니펫 답변 파이프라인 + 경량 2단계(입력분석→생성) 구조 구현 (Python · OpenAI)
  • [1순위] 핵심 화면·기능 — 오늘의 미션 UI 개편, 감정일기 작성 플로우, 마음편지 신고+어드민 처리, 금칙어 필터+사전 관리, 어드민 코치 관리, 터치 범위 보정 (Flutter/Dart)
  • [2순위] 기능 확장 — 입력 elicitation(칩/질문) UI, 어드민(AI코치·미션·격언) 관리, 감정일기 캘린더 이모티콘, 오늘의 격언 개선, 회원가입 척도·설문 DB 점검·기본코치 변경
  • [3순위] UI/브랜딩 리뉴얼 — 홈 화면 구조 변경, 디자인 톤 리스킨, 온보딩 시나리오, 출석/로딩 연출(lottie), 커뮤니티 nav 제거, 앱명·로고 교체 및 스토어 반영 (figma·에셋 기반)
  • [4순위] 후속 고도화 — 마음편지 양방향 대화, 이벤트 로그 DB·분석, 사용자/콘텐츠 관리, 격언 배경 AI 자동화, 지난 기록 열람 등 (규모 고려 시 월 유지보수 단계 협의)
  • 레거시 환경 연계 — 기존 TypeScript/Shell/Ruby/JavaScript 레거시 환경과 호환을 유지하며 운영 중 서비스에 안전하게 반영

제안 포인트

1. AI 대화 파이프라인 고도화 경험. OpenAI API 기반의 AI 분석·요약 기능을 헬스케어 앱에 실제로 구현·운영한 경험이 있습니다. 대화 요약 저장(summary memory)과 컨텍스트 주입(context injection) 방식은 AI 코치의 맥락 유지와 응답 일관성을 높이는 핵심 패턴으로, 토큰 비용과 응답 품질의 균형을 고려해 설계합니다.

2. Flutter 앱 + Python 백엔드 통합 개발. Dart 기반 Flutter 앱 프론트엔드와 Python/Node 기반 AI 백엔드를 단일 인력이 일관되게 개발하여, 프론트-백엔드 간 인터페이스 정합성과 커뮤니케이션 오버헤드를 최소화합니다.

3. 레거시 코드 분석·리팩토링. 운영 중 서비스의 기존 코드를 우선 분석하여 영향 범위를 파악하고, 와이어프레임 기반 UI 개편을 기존 구조와 충돌 없이 안전하게 반영합니다.

4. 우선순위 기반 스코프 최적화. 첨부 기능표의 35개 기능을 우선순위로 분해하여, 완성도 평가 기준에 맞춰 1~3순위 24개 기능을 본 기간 내 완성 포함하고, 규모가 큰 4순위(양방향 대화·AI 자동화·로그 분석 등)는 월 단위 유지보수로 안정적으로 이어가는 현실적이고 책임 있는 스코프를 제안합니다.

PRD (Product Requirements Document)

프로젝트 요구사항을 정의하고 기능 범위를 명확히 합니다. 상세 기능 명세는 클라이언트 제공 엑셀(우선순위 1~4순위) 기준으로 킥오프 시 최종 확정합니다.

1. 프로젝트 배경 및 목적

현재 운영 중인 멘탈케어 모바일 앱의 AI 코치 대화 품질이 맥락 유지·일관성 측면에서 개선이 필요한 상황입니다. 본 프로젝트는 ① 대화 요약 저장 및 파이프라인 주입 방식의 백엔드 고도화로 AI 대화 품질을 향상시키고, ② 와이어프레임 기반 홈·미션·일기 화면 개편으로 사용성을 개선하며, ③ 관리자 웹 기능을 확장하여 운영 효율을 높이는 것을 목표로 합니다.

3. 기능 요구사항 (우선순위 기능표 기준)

3.1 [1순위] 핵심 기능 — 본 기간 포함

  • AI 코치 백엔드 고도화 — 메모리 v1(대화 요약 저장·주입) + 코치별 few-shot·기법 스니펫 답변 파이프라인(주입/선택) + 경량 2단계(입력분석→생성) 구조 (클라 제공: 예시·기법 콘텐츠)
  • 오늘의 미션 UI 개편 — 길이별 박스 가변, 전체보기/체크 분리(체크박스 우측), 편집 모드 figma 시안 일치, 편집 진입 시 체크 오작동 수정 (figma)
  • 감정일기 작성 플로우 — 작성 아이콘·저장·수정·닫기 버튼, 이모티콘 선택 (figma)
  • 마음편지 신고 + 어드민 처리 — 신고 버튼 → 어드민 신고목록 조회 → 게시글 삭제/비공개 처리 (figma)
  • 금칙어 필터 + 어드민 관리 — 입력 필터 적용 + 어드민 사전(단어) 관리
  • 어드민 코치 추가 관리 — 코치 등록·관리
  • UI/UX 터치 범위 보정 — 히트영역 확대

3.2 [2순위] 기능 확장 — 본 기간 포함

  • AI 코치 — 입력 elicitation UI(칩/질문 2~3개 랜덤 표시·연동), 입력 글자수 제한(30자) 완화/해제
  • 어드민 — AI 코치 칩/질문 목록 관리, 미션 풀 편집·관리(엑셀 업로드 등), 격언 배경 이미지 등록·교체·글씨 색 관리
  • 감정일기 — 캘린더에 일기 이모티콘 매핑 표시 (figma)
  • 오늘의 격언 — 길이별 박스 자동 조정·텍스트 잘림 해소, 지난 격언 이미지 열람
  • 회원가입 — 첫인상 설문 척도 문항 수정, 설문 응답↔DB 연동·적재 점검, 기본코치 기본값 변경(클라우드→리버)

3.3 [3순위] UI/브랜딩 리뉴얼 — 본 기간 포함 (개편 화면에 흡수)

  • 홈 화면 구조 변경 — figma대로 재구성 (figma)
  • 디자인 톤 적용/리스킨 — figma대로(가능 시 개편 화면에 흡수)
  • 온보딩 시나리오 화면 — figma대로 구현
  • 출석/로딩 연출 — 에셋(lottie 등) 적용
  • 커뮤니티 nav 제거 + 앱명·로고 교체 (에셋 교체 + 스토어 반영)

3.4 [4순위] 후속 고도화 — 월 유지보수 단계 협의

  • 마음편지 양방향 대화(답장 구조), 비공개/익명 사후 수정, 익명 시 코치 프로필 이미지, 종료 시 만족도 모달
  • 이벤트 로그 DB 적재 + 어드민 조회, 사용자 관리, 콘텐츠 등록·관리
  • 오늘의 격언 배경 AI 자동 생성·선정 알고리즘
  • 지난 기록 — 지난 미션(날짜별 묶음)·지난 일기(월별·연도별) 열람
  • 콘텐츠 기능 추가 (범위 미정 — 협의 후 결정)
