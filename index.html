핵심 요구사항 분석

  • AI 코치 백엔드 고도화 — 대화 요약 저장 및 파이프라인 주입 방식으로 AI 대화 품질·맥락 유지력 향상 (Python · OpenAI)
  • 앱 UI 개편 — 제공된 와이어프레임 기반 홈 화면·미션·일기 등 주요 기능 화면의 사용성 개선 (Flutter/Dart)

  • 레거시 환경 연계 — 기존 TypeScript/Shell/Ruby/JavaScript 레거시 환경과의 호환을 유지하며 개발

제안 포인트

1. AI 대화 파이프라인 고도화 경험. OpenAI API 기반의 AI 분석·요약 기능을 헬스케어 앱에 실제로 구현·운영한 경험이 있습니다. 대화 요약 저장(summary memory)과 컨텍스트 주입(context injection) 방식은 AI 코치의 맥락 유지와 응답 일관성을 높이는 핵심 패턴으로, 토큰 비용과 응답 품질의 균형을 고려해 설계합니다.

2. Flutter 앱 + Python 백엔드 통합 개발. Dart 기반 Flutter 앱 프론트엔드와 Python/Node 기반 AI 백엔드를 단일 인력이 일관되게 개발하여, 프론트-백엔드 간 인터페이스 정합성과 커뮤니케이션 오버헤드를 최소화합니다.

3. 레거시 코드 분석·리팩토링. 운영 중 서비스의 기존 코드를 우선 분석하여 영향 범위를 파악하고, 와이어프레임 기반 UI 개편을 기존 구조와 충돌 없이 안전하게 반영합니다.

4. 고정 예산 최적화. 800만 원 고정 예산과 우선순위(완성도 우선) 조건에 맞춰, 1~2순위 핵심 기능을 완성도 있게 우선 구현하고 3~4순위는 잔여 예산·일정 범위에서 단계적으로 협의하는 현실적 스코프를 제안합니다.

PRD (Product Requirements Document)

프로젝트 요구사항을 정의하고 기능 범위를 명확히 합니다. 상세 기능 명세는 클라이언트 제공 엑셀(우선순위 1~4순위) 기준으로 킥오프 시 최종 확정합니다.

1. 프로젝트 배경 및 목적

현재 운영 중인 멘탈케어 모바일 앱의 AI 코치 대화 품질이 맥락 유지·일관성 측면에서 개선이 필요한 상황입니다. 본 프로젝트는 ① 대화 요약 저장 및 파이프라인 주입 방식의 백엔드 고도화로 AI 대화 품질을 향상시키고, ② 와이어프레임 기반 홈·미션·일기 화면 개편으로 사용성을 개선하며, ③ 관리자 웹 기능을 확장하여 운영 효율을 높이는 것을 목표로 합니다.

2. 사용자 정의

운영 관리자서비스 운영·모니터링 담당관리자 웹 기능, 사용자/콘텐츠 관리, 대화 모니터링

3. 기능 요구사항

3.1 AI 코치 백엔드 고도화 (Python · OpenAI)

  • [필수] 대화 요약 저장 — 대화 세션을 요약하여 저장하고, 장기 맥락(summary memory)으로 관리
  • [필수] 파이프라인 주입 — 저장된 요약을 프롬프트 컨텍스트에 주입하여 AI 코치의 맥락 유지력 향상
  • [필수] OpenAI 프롬프트·응답 처리 로직 고도화 (응답 품질·토큰 효율 균형)
  • [선택] 요약 품질·안전성(민감 정보) 가드레일 보강

3.2 앱 UI 개편 (Flutter · Dart)

  • [필수] 홈 화면 개편 (제공 와이어프레임 기반)
  • [필수] 미션 화면 개편
  • [필수] 일기 화면 개편 및 공통 컴포넌트 정리
  • [선택] 화면 전환·인터랙션 디테일 개선

3.3 관리자 웹

  • [필수] 운영에 필요한 관리자 페이지 기능 추가
  • [선택] AI 대화 로그·요약 모니터링 뷰

5. 기술 제약사항

메인 언어는 Dart(Flutter)·Python으로 고정되며, 서브 언어로 TypeScript·Shell·Ruby·JavaScript 등 기존 레거시 환경이 혼재합니다. 기획·디자인·와이어프레임은 클라이언트 측에서 제공하며, 파트너는 개발에만 집중합니다. 최대 예산은 800만 원으로 고정되어 있으며, 상세 과업 범위는 첨부 엑셀의 우선순위(1~4순위)를 기준으로 산정합니다.

6. 범위 외 사항 (Out of Scope)

  • 신규 기획 및 와이어프레임 제작 (클라이언트 제공)
  • UI 디자인 에셋 제작 (클라이언트 제공)
  • 엑셀 우선순위 중 예산·일정을 초과하는 후순위(3~4순위) 항목 — 잔여 범위 내 단계적 협의
  • 외부 유료 API 사용료 및 서버 인프라 비용
